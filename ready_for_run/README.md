# Ready for run

Everything needed to run the spin simulation notebook, with no programming and no repository.
Todo lo necesario para correr el cuadernillo de simulación de espines, sin programar y sin el repositorio.

| File / Archivo | |
|---|---|
| `configurator.html` | SCK configurator: open it in a browser, set the run, see the Hamiltonian and the lattice, download the .ipynb or .py / Configurador SCK: ábralo en el navegador, configure la corrida, vea el hamiltoniano y la red, descargue el .ipynb o el .py |
| `spin_simulation.ipynb` | The notebook: upload it to Kaggle or Colab / El cuadernillo: súbalo a Kaggle o Colab |
| `MANUAL_en.pdf`, `MANUAL_en.md` | User manual in English |
| `MANUAL_es.pdf`, `MANUAL_es.md` | Manual de uso en español |

`python notebooks/build_simulation_notebook.py && python notebooks/build_configurator.py && python notebooks/build_manuals.py` regenerates this folder.
