# Ready for run

Everything needed to run the spin simulation notebook, with no programming and no repository.
Todo lo necesario para correr el cuadernillo de simulación de espines, sin programar y sin el repositorio.

| File / Archivo | |
|---|---|
| `spin_simulation.ipynb` | The notebook: upload it to Kaggle or Colab / El cuadernillo: súbalo a Kaggle o Colab |
| `MANUAL_en.pdf`, `MANUAL_en.md` | User manual in English |
| `MANUAL_es.pdf`, `MANUAL_es.md` | Manual de uso en español |

`python notebooks/build_simulation_notebook.py && python notebooks/build_manuals.py` regenerates this folder.
